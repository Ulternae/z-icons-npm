# ZCorvus Icons 3.0.0-beta.1

These notes are prepared for a GitHub prerelease corresponding to the already published npm beta. They are not evidence that a GitHub release has been created.

Suggested GitHub tag: `v3.0.0-beta.1`. Target the package release-preparation commit [68608e4c0](https://github.com/Ulternae/z-icons-npm/commit/68608e4c0), confirm the full commit in GitHub, and mark the release as a prerelease.

## Packages

- [`@zcorvus/icons@3.0.0-beta.1`](https://www.npmjs.com/package/@zcorvus/icons/v/3.0.0-beta.1)
- [`@zcorvus/icons-react@3.0.0-beta.1`](https://www.npmjs.com/package/@zcorvus/icons-react/v/3.0.0-beta.1)

Both are distributed under the npm `beta` tag. The `latest` tag remains on the legacy `0.1.x` line.

~~~bash
pnpm add @zcorvus/icons@3.0.0-beta.1 @zcorvus/icons-react@3.0.0-beta.1
~~~

Install only the package needed by the application when using a single rendering target.

## Included in this beta

- Two independent packages generated from the same SVG source catalog.
- Framework-independent definitions, SVG-string rendering, and explicit Web Component registration.
- Named React components by pack and direct import paths for individual icons.
- TypeScript autocomplete for components and explicit dynamic `createZIcon` registries.
- Name-only lists and opt-in maps for complete packs and variants.
- MIT licensing with the original Myna UI artwork notice included in both packages.

## Migration

The v3 API changes the legacy `0.1.x` import and registry model. Import React components from entries such as `@zcorvus/icons-react/mina`, create dynamic subsets with `createZIcon`, and register browser definitions through `@zcorvus/icons/web`.

Only the two current packages are built from this repository. Legacy standalone pack packages and the separate Web package are not part of the v3 build.

## Beta limitations

The API may change before a stable release. Complete `packs-data` maps include their full selected catalog, so bundle cost should be measured in the consumer application. SVG renderers expect trusted generated definitions.

Report reproducible issues through the repository's issue forms and use the [security policy](https://github.com/Ulternae/z-icons-npm/blob/main/SECURITY.md) for sensitive reports.
